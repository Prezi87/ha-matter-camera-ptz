# Matter Camera PTZ v0.3.0 — first public release

This is the first HACS-installable release validated on **Aqara Camera Hub G350**.

## Highlights
- Native Home Assistant camera entity: local Matter 1.5 WebRTC live video and JPEG snapshots, no RTSP/go2rtc required.
- Standard Matter PTZ pan, tilt and zoom with relative press-duration joystick controls.
- Matter privacy sensors: hardware privacy, livestream privacy, recording privacy and combined live-view blocking state.
- Optional **Privacy mode** switch writing Matter soft privacy settings; physical lens retract/expose confirmed on Aqara G350.
- Bundled Lovelace live-picture + PTZ joystick card, including automatic video restart after privacy changes.
- HACS custom repository structure, public installation guide and CI validation.

## Requirements
- Matter Server WebSocket API schema 14+ for native WebRTC video.
- A commissioned and reachable camera exposing Matter PTZ cluster 1362.
- Home Assistant; HACS for automatic installation/update.
- Register the bundled card manually as a JavaScript module at:
  `/matter_camera_ptz/matter-camera-ptz-card.js?v=0.3.0`

## Tested
- Aqara Camera Hub G350, local Matter WebRTC, snapshot, PTZ, lens privacy.
- OpenWrt blocks camera WAN while Matter LAN features remain usable.

## Known issues
- On the tested WAN-blocked G350, first live video appears about 7 seconds after restarting monitoring: [#3](https://github.com/Prezi87/ha-matter-camera-ptz/issues/3).
- Other brands are not yet verified; soft privacy need not physically retract lenses.
- Long-running and multi-viewer reconnect behavior requires more testing.

## Install / upgrade
Add `Prezi87/ha-matter-camera-ptz` in HACS **Custom repositories → Integration**,
select `v0.3.0`, restart HA, then configure Matter Camera PTZ in Devices & Services.
Existing test users should back up `custom_components/matter_camera_ptz` before upgrading.
No Matter fabric reset or re-pairing is required.

See the repository README for dashboard YAML, troubleshooting and security guidance.
