# Matter Camera PTZ v0.3.1 — stability fixes

Patch release following real-device validation on Aqara Camera Hub G350.

## Changes
- **Lovelace lifecycle**: preserve the existing embedded HA camera player DOM when HA temporarily detaches and reattaches the same card while opening/closing dashboard edit mode. Avoid unnecessary card rerenders on unchanged `setConfig()`. Optional `debug: true` logging helps diagnose recreation vs reconnection ([PR #8](https://github.com/Prezi87/ha-matter-camera-ptz/pull/8)).
- **Native WebRTC signaling**: queue camera ICE candidates until the SDP answer is delivered, then allow a short browser setup grace period before sending candidates. This mitigates `InvalidStateError: addIceCandidate: The remote description was null`, which was no longer reproduced in G350 physical tests ([PR #9](https://github.com/Prezi87/ha-matter-camera-ptz/pull/9)).

## Known limitations
- On a G350 with its internet access blocked by OpenWrt, live frames appear about 5–7 seconds after privacy is switched OFF. Direct Matter Server Live View and RTSP tests showed similar delays. This appears related to the camera/WAN isolation rather than the card, but root cause was **not proven**. The delay is accepted for now ([#3](https://github.com/Prezi87/ha-matter-camera-ptz/issues/3)).
- Neither edit-mode DOM preservation nor SDP/ICE ordering guarantees an already-connected HA WebRTC player stays connected when Home Assistant detaches its player.
- Other Matter camera models remain unverified.

## Not included
- No RTSP video fallback (experimental [PR #10](https://github.com/Prezi87/ha-matter-camera-ptz/pull/10) closed).
- No explicit empty ICE server list (ineffective [PR #11](https://github.com/Prezi87/ha-matter-camera-ptz/pull/11) closed).

## Upgrade from v0.3.0
1. Back up Home Assistant configuration and the `custom_components/matter_camera_ptz` folder before replacing experimental files.
2. In **HACS** update Matter Camera PTZ to `v0.3.1`, then restart Home Assistant.
3. In **Settings → Dashboards → Resources**, ensure there is exactly one JavaScript module resource and update it to `/matter_camera_ptz/matter-camera-ptz-card.js?v=0.3.1`. Hard-refresh or reopen the browser.
4. Keep existing camera, PTZ, switch, binary sensor, and Matter Server node/fabric; **no re-pairing**.
5. Test live camera, PTZ and privacy toggle. Remove diagnostic `debug: true` from the dashboard after testing.

Important: UI files manually copied from experimental branches will be replaced when installing the release. No Home Assistant or Matter Server configuration is automatically deleted.
